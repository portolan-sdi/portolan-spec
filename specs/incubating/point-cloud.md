# Incubating — Point Cloud

**Status: deferred, awaiting a reference implementation.**

Point cloud support is not yet implemented. When complete, point cloud data MUST be
provided as [Cloud-Optimized Point Cloud
(COPC)](https://copc.io/), with the media type `application/vnd.laszip+copc`.

Full requirements — statistics, styling, partitioning, and the exact STAC modeling
— will follow a reference implementation. Until then, this is a placeholder marking
the intended direction, and the [Point Cloud](../portolan/formats.md#point-cloud)
section of `formats.md` points here.
