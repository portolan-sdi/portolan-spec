# نموذج مشاهد نقطية

ستة عشر مشهدا صغيرا بصيغة COG في صورة عناصر STAC، مع مرآة عناصر بصيغة stac-geoparquet. المشاهد شبكة 4 في 4 مقطوعة من صورة اختبار rasterio فوق جزيرة أندروس في جزر البهاما ضمن UTM 18N.
