# Contributing to Portolan

> **This repository is a read-only mirror.**
>
> To propose spec changes, open a PR in [portolan-cli](https://github.com/portolan-sdi/portolan-cli)
> that modifies files in the `spec/` directory.

See the [portolan-cli contributing guide](https://github.com/portolan-sdi/portolan-cli/blob/main/docs/contributing.md)
for full instructions.

## Code of Conduct

Please read our [Code of Conduct](CODE_OF_CONDUCT.md) before participating.
